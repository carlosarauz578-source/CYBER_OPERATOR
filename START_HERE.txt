DATA FLOW
═════════════════════════════════════════════════════════════════════════════════

1. User submits query (target: "example.com")
                     ↓
2. Target Classifier identifies type (domain/IP/hash/email/etc.)
                     ↓
3. Source Selector chooses which sources to use
                     ↓
4. Query Engine executes connectors in parallel (DNS, RDAP, Crt.sh, etc.)
                     ↓
5. Each connector returns results
                     ↓
6. Result Aggregator correlates results + risk assessment
                     ↓
7. Database caches results
                     ↓
8. User receives unified results via Interface (Web/CLI/API)


TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════════

Problem: "No module named 'dnspython'"
Solution: pip install -r requirements.txt

Problem: "Port 8501 is already in use"
Solution: streamlit run cyber_operator/interface/app.py --server.port 8502

Problem: "Permission denied: python -m cyber_operator.cli"
Solution: python -m cyber_operator.cli -t example.com (full syntax)

Problem: "No results found"
Reason:  Some targets may have no public records; try:
        - Verify target is spelled correctly
        - Use --verbose flag to see which sources ran
        - Check INTEGRATION_STATUS.md for limitations

Problem: "Tests fail"
Solution: Ensure Python 3.8+ and all dependencies installed:
         pip install --upgrade -r requirements.txt
