═════════════════════════════════════════════════════════════════════════════════

Cyber Operator v0.1 es una plataforma modular y completamente funcional para la
recopilación y análisis de inteligencia de ciberseguridad desde múltiples fuentes.

EJEMPLOS DE USO
═════════════════════════════════════════════════════════════════════════════════

CLI - BÚSQUEDA BÁSICA:
    python -m cyber_operator.cli -t example.com

CLI - CON MODO RECOMENDADO:
    python -m cyber_operator.cli -t google.com --mode recommended

CLI - LISTAR TODAS LAS FUENTES:
    python -m cyber_operator.cli --list-sources

CLI - LISTAR CATEGORÍAS:
    python -m cyber_operator.cli --list-categories

CLI - EXPORTAR A JSON:
    python -m cyber_operator.cli -t target.com --format json

CLI - SALIDA DETALLADA:
    python -m cyber_operator.cli -t target.com --verbose

PYTHON API - BÚSQUEDA SIMPLE:
    from cyber_operator.core import Orchestrator
    orchestrator = Orchestrator()
    results = orchestrator.execute_simple_query("example.com")
    print(results)

PYTHON API - BÚSQUEDA AVANZADA:
    from cyber_operator.core import Orchestrator, IntelligenceQuery, SelectionMode
    orchestrator = Orchestrator()
    query = IntelligenceQuery(
        target="example.com",
        selection_mode=SelectionMode.RECOMMENDED
    )
    results = orchestrator.execute_query(query)

SOLUCIÓN DE PROBLEMAS
═════════════════════════════════════════════════════════════════════════════════

Problema: "No module named 'dnspython'"
Solución: pip install -r requirements.txt

Problema: "Port 8501 already in use"
Solución: streamlit run cyber_operator/interface/app.py --server.port 8502

Problema: "No results found"
Razón:    Algunos objetivos no tienen registros públicos
Solución: Verifica que el objetivo esté escrito correctamente
          Usa --verbose para ver qué fuentes se ejecutaron

Problema: "Tests fail"
Solución: Asegúrate de tener Python 3.8+ y todas las dependencias:
         pip install --upgrade -r requirements.txt

Problema: "Permission denied"
Solución: Usa la sintaxis completa:
         python -m cyber_operator.cli -t target.com
