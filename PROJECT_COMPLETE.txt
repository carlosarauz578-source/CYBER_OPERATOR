🔧 TÉCNICAMENTE
═════════════════════════════════════════════════════════════════════════════════

TECNOLOGÍAS:
  • Python 3.8+ (Core)
  • asyncio (Concurrencia)
  • SQLite3 (Base de datos)
  • Streamlit (Interface web)
  • dnspython (Resolución DNS)
  • requests (Llamadas HTTP)
  • pytest/unittest (Testing)

PATRONES:
  • Registry Pattern (Fuentes)
  • Strategy Pattern (Selectores)
  • Observer Pattern (Eventos)
  • Factory Pattern (Conectores)

CARACTERÍSTICAS:
  • Async concurrent queries (5 simultáneas default)
  • Semaphore rate limiting
  • TTL-based result caching
  • Error isolation per connector
  • Private IP detection
  • Target normalization
  • Risk scoring (LOW/MEDIUM/HIGH)
